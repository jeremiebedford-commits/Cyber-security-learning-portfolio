## Virtualisation:

keeps multiple systems running within one physical server  
Hypervisors: are used/can be installed to allow computers to use the same sever by separating each compartment a computer system would run in.  
Two types  
Type 1: Mainly used for hardware running, efficient, fast for professional settings  
Type 2: Mainly used for Os, making easy to install, run and learn  
Can also be used to test for malicious files due to separating the main Os from the sub-Os  
Dockers are used to install and manage  
Containers basically act as the storage within the Virtualisation for the components of the os and they can be separated or kept together based on preference

## Main cloud service models

Infrastructure as a Service (IaaS): You rent basic computing resources such as virtual servers, storage, and networking. You are responsible for managing the operating system and your application, while the provider manages the physical hardware.  
Platform as a Service (PaaS): The cloud provider manages the infrastructure and the operating system. You focus on building, deploying, and running your application without worrying about servers.  
Software as a Service (SaaS): You use a complete application over the internet. The provider manages everything, and you access the software through a browser or app, for example, Gmail or Zoom.  
EC2 (Virtual Computer / Server): EC2 represents a virtual computer in the cloud. Multiple can be added.  
instance Type (for example: t2, t3, m5): Instance types describe how powerful the virtual computer is.
